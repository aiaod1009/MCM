## 主要功能模块

### 模块1：计算候选区域

**文件：** `utils/compute_candidate_region.m`

**功能：** 根据约束条件计算第二检测点的候选区域

**约束条件：**
1. 距离约束：300-800米
2. 交会角约束：60-120度
3. 避免平行方向：排除30度范围内

### 模块2：推荐最优点

**文件：** `utils/recommend_optimal_point.m`

**功能：** 根据90°垂直策略推荐最优第二检测点

**策略：** 
- 左侧推荐（逆时针90°）
- 右侧推荐（顺时针90°）
- 推荐距离：600米

### 模块3：计算交会角

**文件：** `utils/compute_intersection_angle.m`

**功能：** 计算两个检测点对于估计干扰源位置的交会角

## 常见问题

### 问题1：候选区域为空

**解决方案：**
- 放宽 `alpha_range`，如 `[50, 130]`
- 减小 `delta_angle`，如 `25`
- 检查 `d0` 是否合理

### 问题2：图片显示不完整

**解决方案：**
- 在 `plot_candidate_region.m` 中手动调整 `xlim` 和 `ylim`

## 注意事项

1. **角度单位统一**：全部使用度（degree），函数用 `cosd`、`sind`、`atan2d`
2. **角度周期性**：所有角度差都要用 `min(alpha, 360 - alpha)` 处理
3. **凸包边界提取**：注意去掉 `convhull` 返回的重复首尾点
4. **可视化细节**：图例、标注、颜色要清晰易读
