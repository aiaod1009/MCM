## 算法改进总结

### 问题根源
原算法将S2放在S1的垂直方向（相对于θ1），这**不能**保证交会角为90°。

### 解决方案
在距S1为r的圆上采样搜索，找到使从S2指向G_est的方向θ2最接近θ1±90°的点。

### 核心代码
```matlab
% 在S1周围半径r_optimal的圆上采样
angles = 0:1:360;  % 每度采样
min_error = inf;
best_S2 = [];

for angle = angles
    S2_candidate = S1 + r_optimal * [cosd(angle), sind(angle)];
    theta2 = atan2d(G_est(2) - S2_candidate(2), G_est(1) - S2_candidate(1));
    delta = abs(theta2 - theta2_target);
    delta = min(delta, 360 - delta);
    
    if delta < min_error
        min_error = delta;
        best_S2 = S2_candidate;
    end
end
```
