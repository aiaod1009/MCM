## 三、核心模块实现

### 3.1 模块1：计算候选区域 `compute_candidate_region.m`

**功能：** 根据约束条件计算第二检测点的候选区域

**输入：**

```matlab
S1 = [x1, y1];              % 第一检测点坐标
theta1 = 45;                % 第一示向度（度）
r_range = [300, 800];       % 距离范围
alpha_range = [60, 120];    % 交会角范围
delta_angle = 30;           % 排除角度范围
d0 = 800;                   % 估计的干扰源距离
```

**输出：**

```matlab
candidate_points = [...];   % 候选区域内的点集 (N×2矩阵)
boundary_points = [...];    % 候选区域边界点 (M×2矩阵)
```

**算法实现：**

```matlab
function [candidate_points, boundary_points] = compute_candidate_region(S1, theta1, r_range, alpha_range, delta_angle, d0)
    % 步骤1：生成采样网格
    r_min = r_range(1);
    r_max = r_range(2);
    alpha_min = alpha_range(1);
    alpha_max = alpha_range(2);
  
    % 极坐标采样
    r_samples = r_min:50:r_max;         % 距离采样，步长50米
    phi_samples = 0:5:360;              % 角度采样，步长5度
  
    % 转换为笛卡尔坐标
    [R_grid, PHI_grid] = meshgrid(r_samples, phi_samples);
    X_grid = S1(1) + R_grid .* cosd(PHI_grid);
    Y_grid = S1(2) + R_grid .* sind(PHI_grid);
  
    % 展平为点集
    X_flat = X_grid(:);
    Y_flat = Y_grid(:);
  
    % 步骤2：估计干扰源位置
    G_est = S1 + d0 * [cosd(theta1), sind(theta1)];
  
    % 步骤3：筛选满足约束的点
    candidate_points = [];
  
    for i = 1:length(X_flat)
        S2 = [X_flat(i), Y_flat(i)];
      
        % 约束1：距离约束（已通过采样保证，跳过）
      
        % 约束2：交会角约束
        % 从S2到G_est的方向
        theta2 = atan2d(G_est(2) - S2(2), G_est(1) - S2(1));
      
        % 计算交会角
        alpha = abs(theta2 - theta1);
        alpha = min(alpha, 360 - alpha);  % 调整到[0, 180]
      
        if alpha < alpha_min || alpha > alpha_max
            continue;  % 不满足交会角约束，跳过
        end
      
        % 约束3：避免平行方向
        % 从S1到S2的方向
        beta = atan2d(S2(2) - S1(2), S2(1) - S1(1));
      
        % 计算角度差
        delta_beta = abs(beta - theta1);
        delta_beta = min(delta_beta, 360 - delta_beta);
      
        if delta_beta < delta_angle || delta_beta > (180 - delta_angle)
            continue;  % 在排除区域内，跳过
        end
      
        % 通过所有约束，加入候选区域
        candidate_points = [candidate_points; S2];
    end
  
    % 步骤4：提取边界
    if size(candidate_points, 1) >= 3
        % 使用凸包提取边界
        K = convhull(candidate_points(:,1), candidate_points(:,2));
        boundary_points = candidate_points(K, :);
        % 去除重复的首尾点
        boundary_points = boundary_points(1:end-1, :);
    else
        boundary_points = candidate_points;
    end
end
```

**关键点：**

- 使用 `atan2d` 计算角度（返回度数，而非弧度）
- 角度差需要调整到 $[0°, 180°]$ 范围：`min(alpha, 360 - alpha)`
- 凸包计算使用 MATLAB 内置 `convhull` 函数

### 3.2 模块2：推荐最优点 `recommend_optimal_point.m`

**功能：** 根据90°垂直策略推荐最优第二检测点

**输入：**

```matlab
S1 = [x1, y1];              % 第一检测点坐标
theta1 = 45;                % 第一示向度（度）
r_optimal = 600;            % 推荐距离（默认600米）
direction = 'left';         % 方向选择：'left' 或 'right'
```

**输出：**

```matlab
S2_optimal = [x2, y2];      % 推荐的最优第二检测点
```

**算法实现：**

```matlab
function S2_optimal = recommend_optimal_point(S1, theta1, r_optimal, direction)
    % 默认参数
    if nargin < 3
        r_optimal = 600;  % 默认距离600米
    end
    if nargin < 4
        direction = 'left';  % 默认左侧（逆时针90°）
    end
  
    % 计算垂直方向
    if strcmp(direction, 'left')
        phi_optimal = theta1 + 90;  % 左侧（逆时针）
    else
        phi_optimal = theta1 - 90;  % 右侧（顺时针）
    end
  
    % 计算推荐点
    S2_optimal = S1 + r_optimal * [cosd(phi_optimal), sind(phi_optimal)];
end
```

**使用示例：**

```matlab
S1 = [0, 0];
theta1 = 45;
S2_left = recommend_optimal_point(S1, theta1, 600, 'left');   % (-424.3, 424.3)
S2_right = recommend_optimal_point(S1, theta1, 600, 'right'); % (424.3, -424.3)
```

### 3.3 模块3：计算交会角 `compute_intersection_angle.m`

**功能：** 计算两个检测点对于估计干扰源位置的交会角

**输入：**

```matlab
S1 = [x1, y1];              % 第一检测点
S2 = [x2, y2];              % 第二检测点
theta1 = 45;                % 第一示向度
d0 = 800;                   % 估计的干扰源距离
```

**输出：**

```matlab
alpha = 85.5;               % 交会角（度）
theta2 = 130.2;             % 第二示向度（度）
```

**算法实现：**

```matlab
function [alpha, theta2] = compute_intersection_angle(S1, S2, theta1, d0)
    % 估计干扰源位置
    G_est = S1 + d0 * [cosd(theta1), sind(theta1)];
  
    % 计算从S2到G_est的方向（第二示向度）
    theta2 = atan2d(G_est(2) - S2(2), G_est(1) - S2(1));
  
    % 计算交会角
    alpha = abs(theta2 - theta1);
    alpha = min(alpha, 360 - alpha);  % 调整到[0, 180]
end
```

function plot_candidate_region(S1, theta1, candidate_points, boundary_points, S2_optimal, r_range, d0, filename)
    figure('Position', [100, 100, 900, 900]);
    hold on;
    axis equal;
    grid on;
  
    % 绘制距离约束圆环
    theta_circle = linspace(0, 2*pi, 100);
  
    % 内圆（300米）
    r_inner = r_range(1);
    circle_inner_x = S1(1) + r_inner * cos(theta_circle);
    circle_inner_y = S1(2) + r_inner * sin(theta_circle);
    plot(circle_inner_x, circle_inner_y, 'k--', 'LineWidth', 1);
  
    % 外圆（800米）
    r_outer = r_range(2);
    circle_outer_x = S1(1) + r_outer * cos(theta_circle);
    circle_outer_y = S1(2) + r_outer * sin(theta_circle);
    plot(circle_outer_x, circle_outer_y, 'k--', 'LineWidth', 1);
  
    % 绘制第一示向度射线
    ray_length = 1000;
    ray_end = S1 + ray_length * [cosd(theta1), sind(theta1)];
    arrow_x = [S1(1), ray_end(1)];
    arrow_y = [S1(2), ray_end(2)];
    plot(arrow_x, arrow_y, 'k-', 'LineWidth', 2);
  
    % 绘制估计的干扰源位置
    G_est = S1 + d0 * [cosd(theta1), sind(theta1)];
    plot(G_est(1), G_est(2), 'bx', 'MarkerSize', 15, 'LineWidth', 3);
  
    % 绘制候选区域（散点）
    if ~isempty(candidate_points)
        scatter(candidate_points(:,1), candidate_points(:,2), 10, 'g', 'filled', 'MarkerFaceAlpha', 0.3);
    end
  
    % 绘制候选区域边界（填充）
    if ~isempty(boundary_points) && size(boundary_points, 1) >= 3
        fill(boundary_points(:,1), boundary_points(:,2), 'g', 'FaceAlpha', 0.2, 'EdgeColor', 'g', 'LineWidth', 2);
    end
  
    % 绘制第一检测点
    plot(S1(1), S1(2), 'ro', 'MarkerFaceColor', 'r', 'MarkerSize', 12);
  
    % 绘制推荐的最优点
    if ~isempty(S2_optimal)

        arrow_y2 = [S2_optimal(2), G_est(2)];
        plot(arrow_x2, arrow_y2, 'm--', 'LineWidth', 1.5);

    % 添加标注
    text(S1(1)+50, S1(2)+50, 'S_1（第一检测点）', 'FontSize', 12);
    text(G_est(1)+50, G_est(2)+50, 'G_{est}（估计干扰源）', 'FontSize', 12, 'Color', 'blue');
    if ~isempty(S2_optimal)
        text(S2_optimal(1)+50, S2_optimal(2)+50, 'S_2^*（推荐点）', 'FontSize', 12, 'Color', 'magenta');
    end
  
    % 设置坐标轴
    xlim([S1(1)-1000, S1(1)+1000]);
    ylim([S1(2)-1000, S1(2)+1000]);
    xlabel('X（米）');
    ylabel('Y（米）');
    title(sprintf('问题2：第二检测点候选区域（\\theta_1 = %.0f°）', theta1));
  
    % 图例
    legend('距离约束（内圆300米）', '距离约束（外圆800米）', '第一示向度', ...
           '估计干扰源', '候选区域点', '候选区域边界', '第一检测点', '推荐最优点', ...
           'Location', 'best');

end

### 3.5 模块5：交会角热力图 `plot_angle_heatmap.m`

**功能：** 绘制极坐标下的交会角热力图

**输入：**

```matlab
S1 = [x1, y1];
theta1 = 45;
d0 = 800;
r_max = 1000;
filename = 'results/problem2_case1_heatmap.png';
```

**输出：** 保存热力图到文件

**算法实现：**

```matlab
function plot_angle_heatmap(S1, theta1, d0, r_max, filename)
    % 生成极坐标网格
    r_samples = 0:20:r_max;
    phi_samples = 0:2:360;
  
    [R_grid, PHI_grid] = meshgrid(r_samples, phi_samples);
  
    % 估计干扰源位置
    G_est = S1 + d0 * [cosd(theta1), sind(theta1)];
  
    % 计算每个点的交会角
    ALPHA_grid = zeros(size(R_grid));
  
    for i = 1:size(R_grid, 1)
        for j = 1:size(R_grid, 2)
            r = R_grid(i, j);
            phi = PHI_grid(i, j);
          
            if r == 0
                ALPHA_grid(i, j) = NaN;
                continue;
            end
          
            % 第二检测点坐标
            S2 = S1 + r * [cosd(phi), sind(phi)];
          
            % 计算交会角
            [alpha, ~] = compute_intersection_angle(S1, S2, theta1, d0);
            ALPHA_grid(i, j) = alpha;
        end
    end
  
    % 绘制极坐标热力图
    figure('Position', [100, 100, 800, 800]);
  
    % 转换为极坐标绘图
    polarplot3d(ALPHA_grid, 'plottype', 'surfn', 'radialrange', [0, r_max], 'angularrange', [0, 360]);
  
    % 如果没有polarplot3d工具箱，使用pcolor替代
    % 转换为笛卡尔坐标
    X_grid = R_grid .* cosd(PHI_grid);
    Y_grid = R_grid .* sind(PHI_grid);
  
    pcolor(X_grid, Y_grid, ALPHA_grid);
    shading interp;
    axis equal;
    colorbar;
    colormap(jet);
    caxis([0, 180]);
  
    xlabel('X（米）');
    ylabel('Y（米）');
    title(sprintf('交会角热力图（\\theta_1 = %.0f°）', theta1));
  
    % 添加颜色条标签
    c = colorbar;
    c.Label.String = '交会角（度）';
  
    % 保存图片
    saveas(gcf, filename);
    fprintf('热力图已保存：%s\n', filename);
end
```

**注意：** 如果 MATLAB 没有 `polarplot3d` 工具箱，使用 `pcolor` 绘制笛卡尔坐标下的热力图。

## 四、主程序流程 `main_problem2.m`

**完整主程序：**

```matlab
%% 问题2 主程序
% 计算第二检测点候选区域并推荐最优点

clear; clc; close all;

%% 1. 加载输入数据
% 可以从文件加载或直接定义
data_file = 'test_data/case1.mat';

if exist(data_file, 'file')
    load(data_file);
else
    % 手动定义测试数据
    S1 = [0, 0];
    theta1 = 45;
    r_range = [300, 800];
    alpha_range = [60, 120];
    delta_angle = 30;

fprintf('=== 问题2：第二检测点选择策略 ===\n');
fprintf('第一检测点：(%.2f, %.2f)\n', S1(1), S1(2));
fprintf('第一示向度：%.2f°\n', theta1);
fprintf('距离范围：[%.0f, %.0f] 米\n', r_range(1), r_range(2));
fprintf('交会角范围：[%.0f°, %.0f°]\n', alpha_range(1), alpha_range(2));

%% 2. 计算候选区域
fprintf('\n--- 计算候选区域 ---\n');
tic;
[candidate_points, boundary_points] = compute_candidate_region(S1, theta1, r_range, alpha_range, delta_angle, d0);
time_compute = toc;

fprintf('候选点数量：%d\n', size(candidate_points, 1));
fprintf('边界点数量：%d\n', size(boundary_points, 1));

%% 3. 推荐最优第二检测点
fprintf('\n--- 推荐最优点 ---\n');

% 左侧推荐点（逆时针90°）
S2_left = recommend_optimal_point(S1, theta1, 600, 'left');
[alpha_left, theta2_left] = compute_intersection_angle(S1, S2_left, theta1, d0);

fprintf('左侧推荐点：(%.2f, %.2f)\n', S2_left(1), S2_left(2));

fprintf('  交会角：%.2f°\n', alpha_left);
fprintf('  第二示向度：%.2f°\n', theta2_left);

% 右侧推荐点（顺时针90°）
S2_right = recommend_optimal_point(S1, theta1, 600, 'right');

fprintf('右侧推荐点：(%.2f, %.2f)\n', S2_right(1), S2_right(2));
fprintf('  距离：%.2f 米\n', norm(S2_right - S1));
fprintf('  交会角：%.2f°\n', alpha_right);
fprintf('  第二示向度：%.2f°\n', theta2_right);

S2_optimal = S2_left;

fprintf('\n--- 生成可视化 ---\n');

output_file_region = 'results/problem2_case1_region.png';
plot_candidate_region(S1, theta1, candidate_points, boundary_points, S2_optimal, r_range, d0, output_file_region);

%% 5. 绘制交会角热力图（可选）
output_file_heatmap = 'results/problem2_case1_heatmap.png';
plot_angle_heatmap(S1, theta1, d0, 1000, output_file_heatmap);

%% 6. 保存结果
fprintf('\n--- 保存结果 ---\n');

results = struct();
results.S1 = S1;
results.theta1 = theta1;
results.candidate_points = candidate_points;
results.boundary_points = boundary_points;
results.S2_left = S2_left;
results.S2_right = S2_right;
results.S2_optimal = S2_optimal;
results.alpha_left = alpha_left;
results.alpha_right = alpha_right;

output_file_mat = 'results/problem2_case1_results.mat';
save(output_file_mat, 'results');
fprintf('结果已保存：%s\n', output_file_mat);

fprintf('\n=== 问题2 完成 ===\n');
```

## 八、常见问题排查

### 问题1：候选区域为空

**原因：** 约束条件过于严格，没有点满足所有约束

**解决：**

1. 放宽 `alpha_range`，如 `[50, 130]`
2. 减小 `delta_angle`，如 `25`
3. 检查 `d0` 是否合理

### 问题2：交会角计算结果异常

**原因：** 角度计算时未正确处理周期性

**解决：**

- 确保使用 `atan2d`（返回度数）
- 角度差需要 `min(alpha, 360 - alpha)`

### 问题3：图片显示不完整

**原因：** 坐标轴范围设置不当

**解决：**

- 在 `plot_candidate_region` 中手动设置 `xlim` 和 `ylim`
