## ⚠️ 常见问题

### 问题1：模块导入失败

**症状**：
```
ImportError: No module named 'simulator_client'
```

**解决**：
- 检查问题3代码是否在 `../problem3/src/`
- 确认sys.path设置正确

---

### 问题2：模拟器连接失败

**症状**：
```
ConnectionError: 无法连接到模拟器
```

**解决**：
- 确认模拟器运行在 http://127.0.0.1:5000
- 检查网络/防火墙设置
- 尝试 --url http://localhost:5000

---

### 问题3：清除率低于100%

**症状**：
```
清除比例: 90.0%
```

**分析**：
1. 检查失败频道的检测点分布
2. 查看定位直径（过大可能漏检）
3. 确认补充采样是否触发

**临时解决**：
- 增加补充采样点数（3→5）
- 降低补充采样触发阈值

---

### 问题4：运行时间过长

**症状**：
```
总虚拟时间: 9000+ 秒 (>150分钟)
```

**分析**：
1. 补充采样点数过多
2. 清除失败次数多（精修+螺旋）

**优化**：
- 调整补充采样策略
- 优化定位算法提高精度
