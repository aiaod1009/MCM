## 🔍 核心算法

### 1. 全向/定向判断算法

**判断依据**：

- 无信号点比例（>15%可能是定向源）
- 角度分布跨度（<200°是定向特征）
- 空间分离度（>1.5是定向特征）

**实现**：`classification/source_classifier.py`

### 2. 楔形交会定位算法

**核心思想**：

- 有信号点 → 构建射线扇形交集
- 无信号点 → 排除不可能区域
- 楔形区域 = 交集 - 排除

**实现**：`classification/wedge_localization.py`

### 3. 补充采样策略

**触发条件**：

- 有信号点数 < 3
- 无信号点数 > 有信号点数

**补充点生成**：

- 在有信号点周围（4个方向，距离300米）
- 在有信号/无信号边界区域

**实现**：`phase1_enhanced_scan.py`

## ⚠️ 注意事项

### 关键假设

1. **定向源覆盖角**：180°（中心线±90°）
2. **有效接收半径**：1000-1500米（与全向源相同）
3. **清除半径**：20米（与全向源相同）

### 易错点

1. **无信号 ≠ 无干扰源**：可能在定向源背面
2. **频道切换**：每次检测前必须切换频道
3. **补充采样点**：确保在区域内（±900米）
