## 🎯 核心功能

### 1. 路径规划

**策略：** 优先级贪心

```python
# 按直径分组
high_priority = [t for t in targets if t.diameter < 25]      # 高精度
medium_priority = [t for t in targets if 25 <= t.diameter < 45]  # 中精度
low_priority = [t for t in targets if t.diameter >= 45]      # 低精度（单点估计）

# 在每组内按距离优化
```

**示例输出：**
```
访问顺序（按优先级）:
   1. 频道1: 中心(100.0, 100.0), D=15.0m, conf=0.90
   2. 频道3: 中心(-300.0, 400.0), D=20.0m, conf=0.85
   3. 频道2: 中心(500.0, -500.0), D=35.0m, conf=0.80
   4. 频道4: 中心(800.0, 800.0), D=50.0m, conf=0.60
```

---

### 2. 清除策略

**流程：**
```python
1. 移动到目标中心
2. ⚠️  切换到目标频道（关键！）
3. 尝试清除
4. 如果失败：
   - 精修定位（大范围）
   - 或螺旋搜索（小范围）
5. 最多尝试3次
```

**⚠️  频道切换是最容易出错的地方！**

每次清除前必须切换：
```python
robot.switch_channel(target.channel_id)  # 必须！
robot.clear()
```

---

### 3. 精修策略

#### 螺旋搜索（小范围）

**适用：** 直径<40米

**算法：** 阿基米德螺线
- 从中心向外螺旋
- 步长10米
- 覆盖全面

**示例：** 半径30米，生成39个搜索点

---

#### 精修定位（大范围）

**适用：** 直径≥40米

**算法：**
1. 在区域边界采样2-3个点
2. 补充测向，获得新数据
3. 重新计算定位区域
4. 移动到新中心，清除

---

### 4. 兜底验证

**流程：**
```python
1. 回到原点(0, 0)
2. 扫描全部20个频道
3. 检查是否有遗漏
4. 如果有遗漏：
   a. 单点估计位置
   b. 移动到估计位置
   c. 螺旋搜索清除
```

**重要性：** 确保100%清除率的最后一道防线！

## ⚠️ 关键注意事项

### 频道切换检查清单

**✅ 必须切换频道的场景：**

1. **清除干扰源前**
```python
robot.switch_channel(target.channel_id)  # 必须！
robot.clear()
```

2. **测向前**
```python
robot.switch_channel(channel_id)
angle = robot.detect_direction()
```

3. **精修后重试前**
```python
robot.switch_channel(target.channel_id)  # 再次切换！
robot.clear()
```

4. **螺旋搜索每个点**
```python
for point in search_points:
    robot.move_to(point)
    robot.switch_channel(target.channel_id)  # 每次都切换！
    robot.clear()
```

**❌ 错误案例：**

```python
# 错误：不切换频道
for target in targets:
    robot.move_to(target.center)
    robot.clear()  # ❌ 只能清除频道1的源！
```

**✅ 正确案例：**

```python
# 正确：每次都切换
for target in targets:
    robot.move_to(target.center)
    robot.switch_channel(target.channel_id)  # ✅ 关键！
    robot.clear()
```
