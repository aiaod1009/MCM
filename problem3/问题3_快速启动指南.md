### 步骤0：诊断模拟器连接（强烈推荐）

在运行完整程序前，先测试模拟器连接：

```bash

python test_simulator_connection.py 202619020062
```

**如果诊断通过，继续步骤1。**  
**如果诊断失败，参考输出的检查清单。**

---

### 步骤1：环境准备（2分钟）

```bash
# 1. 进入项目目录
cd e:/problem/problem3

# 2. 安装依赖
pip install numpy scipy requests
```

---

### 步骤2：启动模拟器（1分钟）

1. 打开模拟器程序（GUI）
2. 点击"开始测试"按钮
3. 确认模拟器正在运行

---

### 步骤3：运行程序（2分钟）

**方法A：使用快速启动脚本（推荐）**

Windows:
```bash
run_problem3.bat
```

Linux/Mac:
```bash
chmod +x run_problem3.sh
./run_problem3.sh
```

**方法B：手动运行**

```bash
cd src
python main_problem3.py 202619020062
```

（将 `202619020062` 替换为你的参赛队号）

## 🎯 关键提示

### 最重要：频道切换！

每次清除前必须切换到目标频道：

```python
robot.switch_channel(target.channel_id)  # 必须！
robot.clear()
```

### 兜底验证不能省略

确保100%清除率的最后防线：

```python
# 回到原点，扫描全部20个频道
# 发现遗漏立即补救
```
