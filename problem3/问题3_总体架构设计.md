# 问题3：自动搜索清除全向干扰源 - 总体架构设计

## 📋 问题理解

### 已知条件

**干扰源特性：**
- 全部全向发射（360°信号）
- 频道编号：1-20（互不相同）
- 每个干扰源对应唯一频道
- 有效接收半径：1000-1500米

**机器狗初始状态：**
- 起点：(0, 0)
- 初始频道：1
- 速度：5 m/s
- 切换频道时间：1秒

**任务目标：**
- 自动搜索所有干扰源
- 逐一清除（到达干扰源位置）
- 优化清除比例和平均清除时间

---

## 🎯 队长的三阶段策略

### 阶段1：枚举频道扫描

**策略要点：**
- 圆心先扫一圈
- 圆环上加2-3个点
- 原因：干扰源有效半径1000-1500米
  - 圆心覆盖内圈
  - 环上点补外圈
  - 两层叠加覆盖1800米圆

**扫描点布局：**
```
         E3
          |
    E2----C----E4
          |
         E5
         
C: 圆心 (0,0)
E2-E5: 环上均布3-5个点
```

**频道扫描：**
- 20个频道全扫
- 找出有信号的频道

### 阶段2：逐源交会定位

**策略要点：**
- 每个有源频道按问题2方法两点交会
- 获得大致位置
- 记录定位区域

### 阶段3：巡游清除

**策略要点：**
- 按位置排序，边走边清
- 定位区小的先清（精度高）
- 落空了邻点精修再清

---

## 🚨 高频易错点警告

### ⚠️ 易错点1：频道切换

**错误做法：**
- 一直用频道1，发现不了其他干扰源
- 无脑循环扫20遍，浪费时间

**正确做法：**
- 扫描全部20个频道
- 每切换一次消耗1秒
- 优化切换策略

### ⚠️ 易错点2：自主搜索

**错误做法：**
- 把干扰源坐标写死在代码里（作弊）
- 预先知道干扰源位置

**正确做法：**
- 算法必须自主搜索
- 输入只有测向得到的角度数据
- 不依赖模拟器的真实坐标

### ⚠️ 易错点3：评价指标

**错误理解：**
- 只追求清除比例，时间很长
- 只追求速度，漏掉很多干扰源

**正确理解：**
- 清除比例和平均清除时间都要兼顾
- 需要权衡速度和完整性

### ⚠️ 易错点4：全向特性

**正确理解：**
- 全向干扰源360°都有信号
- 不存在方向屏蔽
- 只要距离合适就能测出角度

## 🏗️ 总体架构设计

### 系统模块划分

```
┌─────────────────────────────────────────┐
│         问题3：自动搜索清除系统           │
└─────────────────────────────────────────┘
                    │
        ┌───────────┼───────────┐
        │           │           │
    ┌───▼───┐   ┌───▼───┐   ┌───▼───┐
    │ 模块1 │   │ 模块2 │   │ 模块3 │
    │枚举扫描│   │交会定位│   │巡游清除│
    └───┬───┘   └───┬───┘   └───┬───┘
        │           │           │
        ▼           ▼           ▼
    频道信号     定位区域     清除路径
```

### 模块1：枚举频道扫描

**输入：**
- 扫描点位置 P_scan = {C, E1, E2, ..., Ek}
- 频道列表 [1, 2, ..., 20]

**处理：**
- 在每个扫描点
- 遍历所有频道
- 记录每个频道的测向角度

**输出：**
- 有源频道列表 Active_Channels
- 每个频道的测向数据 {channel_id: [(position, angle), ...]}

**时间成本：**
- 移动时间：Σ distance(P_i, P_{i+1}) / 5
- 切换频道时间：k × 20 × 1秒（k个扫描点，20个频道）
- 测向时间：忽略（瞬时）

### 模块2：逐源交会定位

**输入：**
- 有源频道列表 Active_Channels
- 每个频道的测向数据

**处理：**
- 对每个有源频道
- 选择两个合适的检测点
- 应用问题2的交会定位算法
- 计算定位区域（凸包）
- 计算定位区域直径（旋转卡壳）

**输出：**
- 干扰源候选区域列表
  ```
  Target = {
    channel_id: 频道编号,
    region: 定位区域凸包,
    center: 区域中心,
    diameter: 区域直径（不确定度）,
    confidence: 置信度
  }
  ```

### 模块3：巡游清除

**输入：**
- 干扰源候选区域列表

**处理：**
- 按不确定度排序（直径小的优先）
- 规划访问路径（TSP优化）
- 逐个访问区域中心
- 到达后确认清除

**精修策略：**
- 到达区域中心后未发现干扰源
- 在区域边界采样补充测向
- 重新定位，缩小区域
- 再次尝试清除

**输出：**
- 清除的干扰源列表
- 总清除时间
- 清除比例

## 📐 关键数学模型

### 模型1：扫描点布局优化

**目标：** 用最少扫描点覆盖最大范围

**约束：**
- 有效接收半径 R_eff ∈ [1000, 1500] 米
- 扫描点在可达范围内

**设计方案：**

**方案A：圆心+圆环（队长建议）**
```
圆心: C = (0, 0)
圆环半径: r = 900 米（内圈覆盖）
圆环点数: k = 3-5

圆环点坐标：
E_i = (r·cos(2πi/k), r·sin(2πi/k)), i = 0, 1, ..., k-1
```

**覆盖分析：**
- 圆心C覆盖半径：1000-1500米
- 圆环点E_i覆盖半径：1000-1500米
- E_i距离原点：900米

**最大覆盖半径：**
```
R_max = 900 + 1500 = 2400米（最外圈）
R_min = 1000米（圆心直接覆盖）
```

**两层叠加：**
- 内圈：0-1500米（圆心C覆盖）
- 外圈：900-2400米（环上点覆盖）
- 重叠区：900-1500米（双重保险）

**扫描点数量：**
- k=3：总共4个点（1中心+3环）
- k=4：总共5个点
- k=5：总共6个点

**队长建议：k=3-5**

### 模型2：频道扫描策略

**朴素方案：每个点扫全部频道**
```
for each point P in {C, E1, E2, ..., Ek}:
    for channel in [1, 2, ..., 20]:
        switch to channel  # 1秒
        angle = detect_direction()
        record(channel, P, angle)
```

**时间成本：**
- 扫描点数：k+1
- 频道数：20
- 切换时间：(k+1) × 20 × 1秒 = 20(k+1)秒
- 移动时间：~（粗估）

**优化方案：智能频道扫描**
- 第一轮：在圆心C扫描全部20个频道
- 记录有信号的频道 Active_Channels
- 后续点：只扫描有信号的频道

**时间节省：**
```
假设只有m个有源频道（m < 20）

朴素方案：20(k+1)秒
优化方案：20 + k×m秒

节省时间：20k - k×m = k(20-m)秒

例如：k=4, m=5
节省：4×(20-5) = 60秒
```

### 模型3：交会定位精度

**输入：**
- 检测点1：S1, 示向度θ1, 误差±1°
- 检测点2：S2, 示向度θ2, 误差±1°

**输出：**
- 定位区域凸包 Hull
- 区域直径 D（不确定度）

**精度因素：**
1. 交会角α（两条示向线夹角）
   - α≈90°：精度最高
   - α≈0°或180°：精度很低
   
2. 检测点距离 d = ||S1 - S2||
   - d太小：定位区域大
   - d太大：可能不在交集内
   
3. 干扰源距离
   - 距离远：角度误差放大
   - 距离近：定位更精确

**选择策略：**
- 从扫描点中选择两个点
- 使交会角尽量接近90°
- 距离适中（600-1000米）

**复用问题2的算法：**
- recommend_optimal_point.m
- compute_candidate_region.m
- rotating_calipers.m

### 模型4：路径规划（TSP变体）

**问题定义：**
- 起点：(0, 0)
- 目标点：{T1, T2, ..., Tm}（干扰源候选位置）
- 优先级：按不确定度排序

**目标函数：**
```
min Total_Time = Σ travel_time + Σ clearing_time

其中：
travel_time = distance / 5
clearing_time = 到达后确认和清除时间（忽略）
```

**约束：**
- 每个目标点访问一次
- 不确定度小的优先访问

**求解方法：**

**方案A：贪心算法（简单）**
```
1. 按不确定度排序目标点
2. 从当前位置选择最近的目标
3. 移动并清除
4. 重复直到所有目标清除
```

**方案B：2-opt优化（更好）**
```
1. 生成初始路径（贪心或按优先级）
2. 尝试交换路径中两个点
3. 如果总距离减少，接受交换
4. 重复直到无法改进
```

**方案C：优先级贪心（队长建议）**
```
1. 按不确定度排序：D1 ≤ D2 ≤ ... ≤ Dm
2. 优先清除不确定度小的（精度高）
3. 在相同优先级内，选择距离近的
4. 动态调整（落空后精修）
```

### 模型5：时间成本模型

**总时间 = 扫描时间 + 定位时间 + 移动时间 + 清除时间**

#### 5.1 扫描时间

**移动到扫描点：**
```
T_scan_move = Σ_{i=1}^{k} distance(P_{i-1}, P_i) / 5

P_0 = (0,0)
P_1 = C = (0,0)（无移动）
P_{i+1} = E_i, i=1,...,k
```

**频道切换与测向：**
```
T_scan_channel = N_switch × 1秒

朴素方案：N_switch = (k+1) × 20
优化方案：N_switch = 20 + k × |Active_Channels|
```

**扫描总时间：**
```
T_scan = T_scan_move + T_scan_channel
```

#### 5.2 定位时间

**计算时间：** 忽略（瞬时完成）

#### 5.3 移动时间

**从起点到第一个目标：**
```
T_move_1 = distance((0,0), T_1) / 5
```

**目标点之间移动：**
```
T_move_inter = Σ_{i=1}^{m-1} distance(T_i, T_{i+1}) / 5
```

**精修移动：**
```
T_move_refine = 每次精修的额外移动时间
```

**移动总时间：**
```
T_move = T_move_1 + T_move_inter + T_move_refine
```

#### 5.4 清除时间

**到达目标点后：**
- 确认干扰源存在（瞬时）
- 清除操作（假设瞬时）

**实际可能包含：**
- 精修定位时间
- 小范围搜索时间

#### 5.5 总时间

```
T_total = T_scan + T_move

对于每个干扰源 i：
T_clear_i = 从发现到清除该源的时间

平均清除时间：
T_avg = Σ T_clear_i / m
```

## 📊 评价指标设计

### 指标1：清除比例

**定义：**
```
清除比例 = 成功清除的干扰源数量 / 实际干扰源总数

Ratio_clear = m_cleared / m_total
```

**目标：** Ratio_clear → 1（接近100%）

### 指标2：平均清除时间

**定义：**
```
平均清除时间 = Σ T_clear_i / m_cleared

T_clear_i = 从起始到清除第i个干扰源的时间
```

**目标：** T_avg → 最小

### 综合评分

**可能的评分函数：**

**方案A：加权和**
```
Score = w1 × Ratio_clear - w2 × T_avg_normalized

w1, w2 为权重
```

**方案B：乘积形式**
```
Score = Ratio_clear × (1 / T_avg)

平衡清除比例和速度
```

**方案C：阈值约束**
```
max Ratio_clear
s.t. T_avg ≤ T_threshold

或

min T_avg
s.t. Ratio_clear ≥ 90%
```

## 🔍 关键技术细节

### 1. 频道切换优化

**智能扫描策略：**

```python
def intelligent_scan(scan_points, total_channels=20):
    # 第一个点：扫描全部频道
    active_channels = []
    
    for ch in range(1, 21):
        switch_channel(ch)  # 1秒
        angle = detect_direction()
        if angle is not None:  # 有信号
            active_channels.append(ch)
            record(ch, scan_points[0], angle)
    
    # 后续点：只扫描有源频道
    for point in scan_points[1:]:
        move_to(point)
        for ch in active_channels:
            switch_channel(ch)  # 1秒
            angle = detect_direction()
            if angle is not None:
                record(ch, point, angle)
    
    return active_channels
```

### 2. 检测点选择策略

**目标：** 选择两个检测点使交会角接近90°

**方法：** 复用问题2的recommend_optimal_point算法

```python
def select_detection_points(scan_data, target_channel):
    # scan_data: {point: angle} for target_channel
    
    # 方案A：暴力枚举所有点对
    best_pair = None
    best_angle = 0
    
    points = list(scan_data.keys())
    for i in range(len(points)):
        for j in range(i+1, len(points)):
            S1, theta1 = points[i], scan_data[points[i]]
            S2, theta2 = points[j], scan_data[points[j]]
            
            # 计算交会角
            intersection_angle = compute_intersection_angle(S1, theta1, S2, theta2)
            
            # 选择最接近90°的
            if abs(intersection_angle - 90) < abs(best_angle - 90):
                best_angle = intersection_angle
                best_pair = (i, j)
    
    return best_pair
```

### 3. 精修策略

**触发条件：** 到达目标中心后未发现干扰源

**精修步骤：**

```python
def refine_localization(target, scan_history):
    # 在定位区域边界采样补充测向点
    boundary_points = sample_boundary(target.region, n=2)
    
    # 补充测向
    new_data = []
    for point in boundary_points:
        move_to(point)
        switch_channel(target.channel)
        angle = detect_direction()
        if angle is not None:
            new_data.append((point, angle))
    
    # 合并历史数据
    all_data = scan_history[target.channel] + new_data
    
    # 重新选择最优检测点对
    S1, theta1, S2, theta2 = select_best_pair(all_data)
    
    # 重新定位
    new_region = compute_candidate_region(S1, theta1, S2, theta2)
    new_center = compute_center(new_region)
    
    # 尝试清除
    move_to(new_center)
    return try_clear(target.channel)
```

### 优先级权重

- 不确定度小优先（精度高）
- 距离近优先（节省时间）

```python
def priority_score(target, current_position):
    # 不确定度越小越好
    uncertainty_score = 1 / (target.diameter + 1)
    
    # 距离越近越好
    distance = norm(target.center - current_position)
    distance_score = 1 / (distance + 1)
    
    # 加权
    w1, w2 = 0.7, 0.3
    return w1 * uncertainty_score + w2 * distance_score
```
