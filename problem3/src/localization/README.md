## 📦 模块列表

### 1. `region_calculator.py` - 定位区域计算

**功能：** 复用问题1的算法，计算两点交会定位的定位区域

**核心函数：** `compute_localization_region(S1, theta1, S2, theta2, error=1.0)`

**算法流程：**
1. 构造4条边界射线（左边界和右边界）
2. 计算所有射线对的交点
3. 筛选在两个扇形内的有效顶点
4. 计算凸包
5. 使用旋转卡壳求直径

**返回：**
```python
{
    'hull': 凸包顶点数组 m×2,
    'diameter': 直径（米）,
    'diameter_endpoints': (V_p, V_q),
    'center': 区域中心坐标 [x, y]
}
```

**测试状态：** ✅ 通过

---

### 2. `point_selector.py` - 检测点选择策略

**功能：** 为单个频道选择最优的两个检测点进行交会定位

**核心函数：**
- `select_detection_points(scan_data_channel)` - 选择最优检测点对
- `evaluate_point_pair_quality(S1, theta1, S2, theta2)` - 评估质量
- `compute_intersection_angle(S1, theta1, S2, theta2)` - 计算交会角

**评分因素：**
- 交会角（权重0.6）：越接近90°越好
- 基线长度（权重0.3）：800-1000米最佳
- 平行性检查（权重0.1）：避免示向度差<10°或>170°

**测试状态：** ✅ 通过
- 两个数据点 ✅
- 多个数据点（暴力枚举）✅
- 单个数据点（返回None）✅
- 交会角计算 ✅

---

### 3. `single_point_estimator.py` - 单点估计

**功能：** 当只有一个检测点的数据时，使用单点估计给出大致位置

**核心函数：** `single_point_estimation(S, theta, R_avg=1250.0)`

**算法原理：**
- 假设干扰源在示向度方向，距离为有效接收半径的平均值（1250米）

**不确定度计算：**
- 径向不确定度：250米（距离范围的一半）
- 切向不确定度：≈22米（角度误差导致）
- 综合不确定度：≈252米

**测试状态：** ✅ 通过
- 不确定度计算验证 ✅
- 不同示向度测试 ✅
- 不同假设距离测试 ✅

### 4. `../target.py` - Target类

**功能：** 表示一个已定位的干扰源，包含定位信息和置信度

**主要属性：**
- `channel_id`: 频道ID
- `center`: 定位中心坐标
- `diameter`: 定位区域直径
- `confidence`: 置信度 (0.0-1.0)
- `method`: 定位方法 ('two_point', 'single_point', 'dynamic')
- `hull`: 凸包顶点（可选）
- `cleared`: 是否已清除

**置信度计算：**
- 直径评分（权重0.5）：直径越小越好
- 交会角评分（权重0.3）：越接近90°越好
- 基线评分（权重0.2）：800-1000米最佳

**测试状态：** ✅ 通过
- Target创建 ✅
- 置信度计算 ✅
- 排序功能 ✅
- JSON序列化 ✅

### 5. `../phase2_localization.py` - 主流程

**功能：** 整合所有定位算法，实现完整的阶段2流程

**核心函数：** `phase2_localization(scan_result, enable_single_point=True, verbose=True)`

**输入：** 阶段1输出结果
```python
{
    'active_channels': [1, 2, 3, ...],
    'scan_data': {
        '1': [[[x, y], theta], ...],
        '2': [...],
        ...
    }
}
```

**输出：** 目标列表（按直径排序）
```python
[
    Target(CH2, center=(499.7, -499.7), diameter=35.3m, conf=0.90, method=two_point),
    Target(CH3, center=(0.0, 1250.0), diameter=501.9m, conf=0.30, method=single_point),
    ...
]
```

**算法流程：**
1. 遍历所有活跃频道
2. 对每个频道：
   - 数据点<2: 单点估计或跳过
   - 数据点>=2: 选择最优检测点对，进行两点交会定位
3. 按直径排序（小→大）

**测试状态：** ✅ 通过
- 合理数据测试 ✅
- 边界情况测试 ✅
- 排序验证 ✅

```python
import numpy as np
from src.localization import (
    compute_localization_region,
    select_detection_points,
    single_point_estimation

S1 = np.array([0.0, 0.0])

theta = 304.24
```

## ⚠️ 已知问题

### 1. 扇形无交集

**问题：** 当两个检测点的示向度配置不当时，扇形区域可能无交集

**原因：**
- 干扰源距离太远
- 示向度差异太小
- 基线方向与示向度夹角过小

**解决方案：**
- 在阶段3增加动态检测点
- 使用更大的误差范围（需要权衡定位精度）

### 2. 单点估计不确定度大

**问题：** 单点估计的不确定度约252米，远大于清除半径20米

**影响：** 无法保证在估计位置清除时能覆盖干扰源

**解决方案：**
- 在阶段3增加精修策略
- 动态增加第二个检测点（如果时间允许）
