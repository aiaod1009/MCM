### 阶段1：枚举频道扫描

**任务：** 发现目标区域内所有有源频道

**策略：** 混合扫描
- 圆心C(0,0)：扫描全部20个频道
- 环点E1(900,0)：再次扫描全部20个频道（避免漏检）
- 其余环点E2/E3/E4：只扫描已发现频道（节省时间）

**覆盖范围：**
- 圆心：0-1500米
- 环点：900-2400米
- 总覆盖：0-1800米圆（满足题目要求）

**实测结果：**

- 成功率：100%

### 阶段2：逐源交会定位

**任务：** 为每个频道计算干扰源位置

**策略：**
1. **两点交会定位**（数据点≥2）
   - 选择最优检测点对
   - 计算扇形交集
   - 求凸包和直径
   - 置信度：0.8-0.95

2. **单点估计**（数据点=1）
   - 假设距离1250米
   - 不确定度≈252米
   - 置信度：0.30

**输出示例：**
```
成功定位 8 个干扰源:
  1. 频道20: 中心(650, 1250), D=16m, conf=0.89, method=two_point
  2. 频道1: 中心(-450, -890), D=18m, conf=0.87, method=two_point
  ...
  8. 频道10: 中心(1580, 1120), D=55m, conf=0.65, method=single_point
```

**关键创新：**
- 质量评分：交会角+基线+平行性
- 检测点选择：暴力枚举所有组合
- 置信度计算：直径+交会角+基线

**测试结果：**
- 几何算法：与MATLAB版本100%一致
- 定位成功率：100%（使用合理数据）
- 单元测试：100%通过

### 阶段3：巡游清除

**任务：** 移动到各目标位置，清除干扰源

**策略：**

#### 1. 路径规划
- **优先级贪心：** 按直径分组，组内按距离优化
- **2-opt优化（可选）：** 减少5-10%移动距离

#### 2. 清除策略
```python
1. 移动到目标中心
2. ⚠️  切换到目标频道（关键！）
3. 尝试清除
4. 如果失败：启动精修
5. 最多尝试3次
```

#### 3. 精修策略
- **螺旋搜索（D<40m）：** 阿基米德螺线，覆盖全面
- **精修定位（D≥40m）：** 边界采样重定位，缩小范围

#### 4. 兜底验证
```python
1. 回到原点(0, 0)
2. 扫描全部20个频道
3. 发现遗漏则补救清除
```

**输出示例：**
```
成功清除: 8/8 (100%)
总虚拟时间: 3250秒 (54.2分钟)
平均清除时间: 180.5秒
```

**关键要点：**
- ⚠️  **频道切换是最容易出错的地方！**
- 每次清除前必须切换到目标频道
- 兜底验证确保100%清除率

## ⚠️ 关键注意事项

### 1. 频道切换（最易出错）

**错误案例：**
```python
# ❌ 不切换频道
for target in targets:
    robot.move_to(target.center)
    robot.clear()  # 只能清除频道1的源！
```

**正确案例：**
```python
# ✅ 每次都切换
for target in targets:
    robot.move_to(target.center)
    robot.switch_channel(target.channel_id)  # 关键！
    robot.clear()
```

**检查清单：**
- [ ] 清除前切换
- [ ] 测向前切换
- [ ] 精修后重新切换
- [ ] 螺旋搜索每个点都切换

---

### 2. 兜底验证（不能省略）

**为什么重要：**
- 确保100%清除率的最后防线
- 发现遗漏立即补救
- 题目要求必须全部清除

**流程：**
```python
1. 回到原点(0, 0)
2. 扫描全部20个频道
3. remaining_channels = [...]  # 遗漏的频道
4. 如果有遗漏：补救清除
```

---

### 3. 优先级排序（提高效率）

**策略：** 直径小的先清除

**理由：**
- 直径小 → 定位精度高 → 清除成功率高
- 避免在低精度目标上浪费时间
- 失败后精修更有针对性

**实现：**
```python
# 阶段2已按直径排序
targets.sort(key=lambda t: t.diameter)

# 阶段3直接使用
path = targets  # 已是最优顺序
```
