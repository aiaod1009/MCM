## 💡 核心算法

### 阶段1：智能快速扫描策略

**策略**：圆心 + 3个方向点全扫（覆盖定向干扰源） + 其余点选择扫描

```python
# 9个扫描点（圆心C + 8个环点，半径900米）
# 前3个点：全频道扫描（20个频道）
# 后6个点：仅扫描已发现频道

# 优势：
# - 快速：仅3个全扫点（~60次检测）
# - 可靠：配合阶段3兜底验证，总体100%清除
# - 总时间：~600秒（10分钟）
```

**时间成本**：
- 3个全扫点 × 20频道 = 60次全扫
- 6个点 × 平均10频道 = 60次选择扫描
- **总计：~120次检测 ≈ 10分钟虚拟时间**

### 阶段2：两点交会定位 + 单点估计

**两点交会**：
1. 从多个检测点中选择最优点对（夹角接近90°）
2. 计算两条射线的扇形交集区域
3. 计算外接圆中心和直径

**单点估计**（兜底）：
- 当数据不足两点时，使用单点 + 经验距离估计

```python
# 输出格式
Target(
    channel_id=1,
    center=[450.0, -230.0],      # 定位中心
    diameter=18.5,                # 不确定直径（米）
    confidence=0.87,              # 置信度
    method='two_point'            # 定位方法
)
```

### 阶段3：巡游清除 + 兜底验证

**流程**：
1. **路径规划**：按优先级排序（高置信度 + 小直径优先）
2. **逐个清除**：移动 → 清除（API自动切换频道）
3. **失败精修**：
   - 补充测向 → 重新定位 → 再次清除
   - 螺旋搜索（半径≤20米，清除半径限制）
4. **兜底验证**：回原点扫描全部20频道，发现遗漏立即补救

**关键机制**：
- ✅ **清除半径20米**（题目规定）
- ✅ **螺旋搜索限制20米**（避免超出清除范围）
- ✅ **兜底验证保证100%**（最后防线）

```python
# 清除API（自动处理移动+频道+清除）
result = robot.clear(position, channel)

# 返回: 'success' 或 'no_target_in_range'
```

如需调整阶段1的扫描策略，编辑 `src/main_problem3.py`:

```python
# 当前：智能快速策略（推荐）
scan_result_obj = scanner.run(strategy='smart')

# 可选策略：
# scanner.run(strategy='hybrid')  # 混合策略（4点全扫，更保守）
```

**策略对比**：

| 策略 | 全扫点 | 阶段1时间 | 阶段1覆盖 | 阶段3补救 | 总时间 | 推荐 |
|------|--------|----------|-----------|----------|--------|------|
| **smart** 🚀 | 3个 | ~600秒 | 60-70% | 30-40% | ~750秒 | ⭐⭐⭐ |
| **hybrid** ⚖️ | 4个 | ~850秒 | 80-90% | 10-20% | ~1150秒 | ⭐⭐ |
| **naive** 🐌 | 5个 | ~600秒 | 95-100% | 0-5% | ~600秒 | ⭐ |

> **注意**：`smart` 策略配合阶段3兜底验证，总时间最优且保证100%清除率

## ⚠️ 常见问题

### Q1: 连接模拟器失败

```
✗ 连接失败: 无法连接到模拟器
```

**解决方案**：
1. 检查模拟器是否启动
2. 确认点击了"开始测试"
3. 验证地址：http://127.0.0.1:2026
4. 确认 `robot_id` 与登录队号一致

### Q2: 阶段1发现频道不全（11/15）

**原因**：部分定向干扰源覆盖角度未被扫描点覆盖

**解决方案**：
- ✅ **推荐**：保持 `smart` 策略，依赖阶段3兜底验证（总时间更优）
- 或切换到 `hybrid` 策略（阶段1覆盖更好，但总时间更长）

### Q3: 清除比例 < 100%

**检查项**：
1. ✅ 确认阶段3执行了兜底验证
2. ✅ 确认 `clear()` API正确调用（自动切换频道）
3. ✅ 确认螺旋搜索半径≤20米（清除半径限制）

### Q4: 虚拟时间超时（>100小时）

**原因**：无限循环或策略效率问题

**解决方案**：
1. 检查是否有无限循环
2. 限制精修和螺旋搜索的最大尝试次数
3. 使用 `smart` 策略减少阶段1时间
