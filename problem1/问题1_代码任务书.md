## 二、数据预处理

### 2.1 输入数据格式

**MATLAB结构体：**

```matlab
input_data = struct();
input_data.n = 3;                    % 检测点数量
input_data.detectors = [
    0,   0;                          % 检测点1坐标 (x1, y1)
    100, 0;                          % 检测点2坐标 (x2, y2)
    50,  100                         % 检测点3坐标 (x3, y3)
];
input_data.azimuths = [45; 135; 225]; % 示向度（度）
input_data.error = 1;                 % 误差范围（度）
```

### 2.2 预处理步骤

**步骤1：角度归一化**

- 将所有角度转换到 $[0, 360)$ 区间
- MATLAB代码：`theta = mod(theta, 360);`

**步骤2：构造边界射线**

- 对每个检测点，计算左右边界射线的方位角
- 左边界：`theta_left = theta - error`
- 右边界：`theta_right = theta + error`
- 处理跨越0度的情况（如 $\theta = 1°$ 时，左边界为 $360°$）

**步骤3：数据存储**

```matlab
rays = struct();
for i = 1:n
    rays(i).origin = detectors(i, :);          % 起点
    rays(i).theta_left = azimuths(i) - error;  % 左边界角度
    rays(i).theta_right = azimuths(i) + error; % 右边界角度
  
    % 方向向量
    rays(i).dir_left = [cosd(rays(i).theta_left), sind(rays(i).theta_left)];
    rays(i).dir_right = [cosd(rays(i).theta_right), sind(rays(i).theta_right)];
end
```

## 三、核心模块实现

### 3.1 模块1：射线交点计算 `ray_intersection.m`

**功能：** 计算两条射线的交点

**输入：**

```matlab
% 射线1：从 origin1 出发，方向向量 direction1
% 射线2：从 origin2 出发，方向向量 direction2
origin1 = [x1, y1];
direction1 = [dx1, dy1];
origin2 = [x2, y2];
direction2 = [dx2, dy2];
```

**输出：**

```matlab
[intersect_point, is_valid] = ray_intersection(origin1, direction1, origin2, direction2);
% intersect_point: [x, y] 交点坐标
% is_valid: 布尔值，true表示有效交点，false表示平行或反向
```

**算法实现：**

```matlab
function [P, is_valid] = ray_intersection(O1, D1, O2, D2)
    % 计算行列式
    delta = D1(1) * D2(2) - D1(2) * D2(1);
  
    % 判断平行
    if abs(delta) < 1e-10
        P = [NaN, NaN];
        is_valid = false;
        return;
    end
  
    % 计算参数 t1, t2
    dx = O2(1) - O1(1);
    dy = O2(2) - O1(2);
  
    t1 = (dx * D2(2) - dy * D2(1)) / delta;
    t2 = (dx * D1(2) - dy * D1(1)) / delta;
  
    % 判断有效性（两个参数都 >= 0）
    if t1 >= 0 && t2 >= 0
        P = O1 + t1 * D1;
        is_valid = true;
    else
        P = [NaN, NaN];
        is_valid = false;
    end
end
```

**关键点：**

- `abs(delta) < 1e-10` 用于判断平行（避免除零）
- `t1 >= 0 && t2 >= 0` 确保交点在射线正向上

### 3.2 模块2：点在扇形内判断 `point_in_sectors.m`

**功能：** 判断点 $P$ 是否在所有检测点的扇形区域内

**输入：**

```matlab
P = [x, y];                  % 待判断点
detectors = [...];           % 检测点坐标矩阵 n×2
azimuths = [...];            % 示向度向量 n×1
error = 1;                   % 误差范围
```

**输出：**

```matlab
is_inside = point_in_sectors(P, detectors, azimuths, error);
% is_inside: 布尔值，true表示点在所有扇形内
```

**算法实现：**

```matlab
function is_inside = point_in_sectors(P, detectors, azimuths, error)
    n = size(detectors, 1);
    is_inside = true;
  
    for i = 1:n
        % 计算从检测点i到P的方位角
        vec = P - detectors(i, :);
        angle_to_P = atan2d(vec(2), vec(1));  % 使用atan2d得到[-180, 180]
        angle_to_P = mod(angle_to_P, 360);    % 转换到[0, 360)
    
        % 计算扇形角度范围
        theta_min = mod(azimuths(i) - error, 360);
        theta_max = mod(azimuths(i) + error, 360);
    
        % 判断是否在扇形内（需处理跨越0度的情况）
        if theta_min <= theta_max
            % 正常情况
            if angle_to_P < theta_min || angle_to_P > theta_max
                is_inside = false;
                return;
            end
        else
            % 跨越0度（如 [359, 1]）
            if angle_to_P < theta_min && angle_to_P > theta_max
                is_inside = false;
                return;
            end
        end
    end
end
```

**关键点：**

- `atan2d` 返回 $[-180°, 180°]$，需要转换到 $[0°, 360°)$
- 跨越0度的判断逻辑要仔细处理

### 3.3 模块3：凸包计算 `compute_convex_hull.m`

**功能：** 计算有效顶点的凸包

**输入：**

```matlab
vertices = [...];  % 有效顶点坐标矩阵 m×2
```

**输出：**

```matlab
hull_vertices = compute_convex_hull(vertices);
% hull_vertices: 凸包顶点坐标矩阵，按逆时针排列
```

**算法实现（使用MATLAB内置函数）：**

```matlab
function hull = compute_convex_hull(vertices)
    if size(vertices, 1) < 3
        hull = vertices;
        return;
    end
  
    % 使用MATLAB内置凸包函数
    K = convhull(vertices(:,1), vertices(:,2));
  
    % convhull返回的最后一个点是第一个点的重复，需要去掉
    hull = vertices(K(1:end-1), :);
end
```

**关键点：**

- `convhull` 返回的索引列表最后一个元素是首元素的重复，需去掉

### 3.4 模块4：旋转卡壳算法 `rotating_calipers.m`

**功能：** 计算凸包的直径

**输入：**

```matlab
hull = [...];  % 凸包顶点矩阵 m×2（按逆时针排列）
```

**输出：**

```matlab
[diameter, p1, p2] = rotating_calipers(hull);
% diameter: 直径长度
% p1, p2: 直径对应的两个端点坐标
```

**算法实现：**

```matlab
function [D, V_p, V_q] = rotating_calipers(hull)
    m = size(hull, 1);
    if m < 2
        D = 0;
        V_p = hull(1, :);
        V_q = hull(1, :);
        return;
    end
  
    D = 0;
    V_p = hull(1, :);
    V_q = hull(1, :);
  
    % 找初始最远点对
    j = 1;
    for i = 0:(m-1)
        i_idx = mod(i, m) + 1;
        j_idx = mod(j, m) + 1;
    
        % 当前边向量
        edge = hull(mod(i+1, m) + 1, :) - hull(i_idx, :);
    
        % 旋转j直到不能再增加投影
        while true
            j_next = mod(j+1, m) + 1;
            vec_j = hull(j_next, :) - hull(j_idx, :);
        
            % 叉积判断是否继续旋转
            cross_prod = edge(1) * vec_j(2) - edge(2) * vec_j(1);
        
            if cross_prod > 0
                j = j + 1;
                j_idx = mod(j, m) + 1;
            else
                break;
            end
        end
    
        % 计算当前距离
        dist = norm(hull(i_idx, :) - hull(j_idx, :));
        if dist > D
            D = dist;
            V_p = hull(i_idx, :);
            V_q = hull(j_idx, :);
        end
    end
end
```

**关键点：**

- MATLAB数组索引从1开始，需要用 `mod(..., m) + 1` 处理循环索引
- 叉积 `cross_prod > 0` 表示应该继续移动 $j$ 指针

### 3.5 模块5：可视化 `plot_localization_region.m`

**功能：** 绘制定位区域、边界射线、凸包、直径

**输入：**

```matlab
detectors = [...];     % 检测点坐标
azimuths = [...];      % 示向度
error = 1;             % 误差
hull = [...];          % 凸包顶点
diameter = ...;        % 直径长度
V_p = [...];           % 直径端点1
V_q = [...];           % 直径端点2
```

**输出：** 保存图片到文件

**算法实现：**

```matlab
function plot_localization_region(detectors, azimuths, error, hull, D, V_p, V_q, filename)
    figure('Position', [100, 100, 800, 800]);
    hold on;
    axis equal;
    grid on;
  
    n = size(detectors, 1);
    ray_length = max(1000, D * 2);  % 射线显示长度
  
    % 绘制边界射线
    for i = 1:n
        origin = detectors(i, :);
    
        % 左边界射线
        theta_L = azimuths(i) - error;
        dir_L = [cosd(theta_L), sind(theta_L)];
        endpoint_L = origin + ray_length * dir_L;
        plot([origin(1), endpoint_L(1)], [origin(2), endpoint_L(2)], 'r--', 'LineWidth', 0.5);
    
        % 右边界射线
        theta_R = azimuths(i) + error;
        dir_R = [cosd(theta_R), sind(theta_R)];
        endpoint_R = origin + ray_length * dir_R;
        plot([origin(1), endpoint_R(1)], [origin(2), endpoint_R(2)], 'b--', 'LineWidth', 0.5);
    
        % 中心示向度射线
        dir_C = [cosd(azimuths(i)), sind(azimuths(i))];
        endpoint_C = origin + ray_length * dir_C;
        plot([origin(1), endpoint_C(1)], [origin(2), endpoint_C(2)], 'k-', 'LineWidth', 1.5);
    end
  
    % 绘制检测点
    plot(detectors(:,1), detectors(:,2), 'ko', 'MarkerFaceColor', 'yellow', 'MarkerSize', 10);
  
    % 绘制凸包（定位区域）
    if ~isempty(hull)
        hull_closed = [hull; hull(1,:)];  % 闭合多边形
        fill(hull_closed(:,1), hull_closed(:,2), 'cyan', 'FaceAlpha', 0.3, 'EdgeColor', 'blue', 'LineWidth', 2);
    end
  
    % 绘制直径
    plot([V_p(1), V_q(1)], [V_p(2), V_q(2)], 'm-', 'LineWidth', 3);
    plot(V_p(1), V_p(2), 'mo', 'MarkerFaceColor', 'magenta', 'MarkerSize', 8);
    plot(V_q(1), V_q(2), 'mo', 'MarkerFaceColor', 'magenta', 'MarkerSize', 8);
  
    % 绘制以直径为直径的圆
    circle_center = (V_p + V_q) / 2;
    circle_radius = D / 2;
    theta_circle = linspace(0, 2*pi, 100);
    circle_x = circle_center(1) + circle_radius * cos(theta_circle);
    circle_y = circle_center(2) + circle_radius * sin(theta_circle);
    plot(circle_x, circle_y, 'g-', 'LineWidth', 2);
  
    % 添加标注
    title(sprintf('定位区域与直径 (D = %.2f 米)', D));
    xlabel('X (米)');
    ylabel('Y (米)');
    legend('左边界射线', '右边界射线', '示向度中心', '检测点', '定位区域', '直径', '', '', '覆盖圆');
  
    % 保存图片
    saveas(gcf, filename);
    hold off;
end
```

## 四、主程序流程 `main_problem1.m`

**完整主程序：**

```matlab
%% 问题1 主程序
% 计算交会定位区域直径并验证覆盖性

clear; clc; close all;

%% 1. 加载输入数据
input_data = load('test_data/sample_case1.mat');
detectors = input_data.detectors;
azimuths = input_data.azimuths;
error = input_data.error;
n = size(detectors, 1);

fprintf('=== 问题1：定位区域直径计算 ===\n');
fprintf('检测点数量: %d\n', n);

%% 2. 构造边界射线
rays = [];
ray_count = 0;
for i = 1:n
    % 左边界射线
    ray_count = ray_count + 1;
    rays(ray_count).origin = detectors(i, :);
    rays(ray_count).theta = mod(azimuths(i) - error, 360);
    rays(ray_count).direction = [cosd(rays(ray_count).theta), sind(rays(ray_count).theta)];
  
    % 右边界射线
    ray_count = ray_count + 1;
    rays(ray_count).origin = detectors(i, :);
    rays(ray_count).theta = mod(azimuths(i) + error, 360);
    rays(ray_count).direction = [cosd(rays(ray_count).theta), sind(rays(ray_count).theta)];
end

fprintf('边界射线数量: %d\n', ray_count);

%% 3. 计算所有射线交点
candidates = [];
for i = 1:(ray_count-1)
    for j = (i+1):ray_count
        [P, is_valid] = ray_intersection(rays(i).origin, rays(i).direction, ...
                                          rays(j).origin, rays(j).direction);
        if is_valid
            candidates = [candidates; P];
        end
    end
end

fprintf('候选交点数量: %d\n', size(candidates, 1));

%% 4. 筛选有效顶点
valid_vertices = [];
for k = 1:size(candidates, 1)
    if point_in_sectors(candidates(k,:), detectors, azimuths, error)
        valid_vertices = [valid_vertices; candidates(k,:)];
    end
end

fprintf('有效顶点数量: %d\n', size(valid_vertices, 1));

%% 5. 计算凸包
hull = compute_convex_hull(valid_vertices);
fprintf('凸包顶点数量: %d\n', size(hull, 1));

%% 6. 旋转卡壳求直径
[D, V_p, V_q] = rotating_calipers(hull);
fprintf('\n=== 计算结果 ===\n');
fprintf('定位区域直径: %.4f 米\n', D);
fprintf('直径端点1: (%.2f, %.2f)\n', V_p(1), V_p(2));
fprintf('直径端点2: (%.2f, %.2f)\n', V_q(1), V_q(2));

%% 7. 验证覆盖性
circle_center = (V_p + V_q) / 2;
circle_radius = D / 2;

% 检查所有凸包顶点是否在圆内
max_dist = 0;
for k = 1:size(hull, 1)
    dist = norm(hull(k,:) - circle_center);
    if dist > max_dist
        max_dist = dist;
    end
end

fprintf('\n=== 覆盖性验证 ===\n');
fprintf('圆心坐标: (%.2f, %.2f)\n', circle_center(1), circle_center(2));
fprintf('圆半径: %.4f 米\n', circle_radius);
fprintf('凸包顶点到圆心的最大距离: %.4f 米\n', max_dist);

if max_dist <= circle_radius + 1e-6
    fprintf('结论: 能够覆盖 ✓\n');
else
    fprintf('结论: 不能完全覆盖 ✗\n');
end

%% 8. 可视化
plot_localization_region(detectors, azimuths, error, hull, D, V_p, V_q, 'results/problem1_case1.png');
fprintf('\n图片已保存: results/problem1_case1.png\n');

%% 9. 保存结果
results = struct();
results.diameter = D;
results.endpoint1 = V_p;
results.endpoint2 = V_q;
results.can_cover = (max_dist <= circle_radius + 1e-6);
save('results/problem1_results.mat', 'results');
```

## 八、常见问题排查

### 问题1：射线交点计算结果为NaN

**原因：** 射线平行或接近平行，行列式接近0
**解决：** 检查 `abs(delta) < 1e-10` 阈值是否合适

### 问题2：没有有效顶点

**原因：** 扇形角度范围设置错误，或检测点配置不合理
**解决：** 打印每个候选点的判断结果，检查 `point_in_sectors` 逻辑

### 问题3：凸包顶点顺序错误

**原因：** `convhull` 返回的可能是顺时针排列
**解决：** 检查凸包顶点顺序，必要时反转

### 问题4：旋转卡壳算法死循环

**原因：** 索引处理错误，`mod(j, m) + 1` 逻辑有误
**解决：** 增加最大迭代次数保护

### 问题5：图片显示不完整

**原因：** 坐标轴范围自动调整不当
**解决：** 手动设置 `xlim` 和 `ylim`
