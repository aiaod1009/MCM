## 详细测试结果

### 用例1：简单三角形配置

**输入**
```
检测点：(0.00, 0.00)、(100.00, 0.00)、(50.00, 80.00)
示向度：45.0°、135.0°、270.0°        误差：±1.0°
```

**计算过程**：边界射线 6 条 → 候选交点 15 个 → 有效顶点 6 个 → 凸包 6 顶点

**凸包顶点坐标**
```
(50.00, 48.28)  (50.54, 48.81)  (50.50, 51.26)
(50.00, 51.78)  (49.50, 51.26)  (49.46, 48.81)
```

**结果**
```
定位区域直径: 3.4921 米
直径端点: (50.00, 48.28) 与 (50.00, 51.78)
圆心: (50.00, 50.03)   圆半径: 1.7460 米
凸包顶点到圆心最大距离: 1.7460 米
结论: 能够完全覆盖 ✓
```

**几何解释**：三个扇形的交集是**六边形**（不是三角形）。两个直径端点恰好落在圆上，
其余 4 个顶点都在圆内，故 $d_{\max}=R$，**能覆盖**。

---

### 用例2：五检测点配置（题面 ±1°）

**输入**
```
检测点：(0,0)、(200,0)、(200,200)、(0,200)、(100,100)
示向度：45°、135°、225°、315°、0°        误差：±1.0°
```

> **误差设定已纠偏**：2026-09-12 前的版本把本用例误差人为放大到 ±5° 才"产生交集"，
> 偏离了题面规定的 $\pm1^\circ$。实测在 ±1° 下五个扇形同样有非空交集，定位区域为
> 一个细长四边形，故已改回 ±1°。放大误差不再作为独立算例，仅在需要讨论误差灵敏度时提及。

**计算过程**：边界射线 10 条 → 候选交点 33 个 → 有效顶点 4 个 → 凸包 4 顶点

**凸包顶点坐标**
```
(100.00, 100.00)  (103.37, 99.94)  (103.43, 100.00)  (103.37, 100.06)
```

**结果**
```
定位区域直径: 3.4311 米
直径端点: (100.00, 100.00) 与 (103.43, 100.00)
圆心: (101.72, 100.00)   圆半径: 1.7156 米
凸包顶点到圆心最大距离: 1.7156 米
结论: 能够完全覆盖 ✓
```

**几何解释**：区域是沿 $x$ 轴的极细长四边形（长 3.4311 m、宽约 0.1178 m，长宽比 ≈ 29:1）。
顶点 (100.00, 100.00) 恰为第 5 个检测点自身（示向度 $0^\circ$ 的楔形顶点），属合法顶点——
这一点很关键：若把它丢掉，有效顶点只剩 3 个，直径会被误算为 0.1178 m（详见说明文档缺陷 B4/B5）。

细长并非偶然：只要某检测点本身是区域顶点，区域在该点必然以张角 $2\epsilon$ 的楔形收敛，
长宽比必然不小于 $1/(2\tan1^\circ)\approx28.6$。

### 用例4：等边三检测点（"圆盖不住"标准反例）

**输入**
```
检测点：位于半径 300 m 的等边三角形顶点
        (300, 0)、(-150, 259.81)、(-150, -259.81)
示向度：180°、300°、60°（均指向原点）        误差：±1.0°
```

**计算过程**：边界射线 6 条 → 候选交点 15 个 → 有效顶点 6 个 → 凸包 6 顶点

**凸包顶点坐标**
```
(2.99, 5.18)   (-3.05, 5.29)   (-5.99, 0.00)
(-3.05, -5.29) (2.99, -5.18)   (6.11, 0.00)
```

**结果**
```
定位区域直径: 12.0945 米
直径端点: (-5.99, 0.00) 与 (6.11, 0.00)
圆心: (0.06, 0.00)   圆半径: 6.0472 米
凸包顶点到圆心最大距离: 6.1389 米  >  6.0472 米
结论: 不能完全覆盖 ✗      超出距离: 0.091640 米
```

**几何解释**：区域是等边三角形般的六边形，**四个顶点凸出于覆盖圆之外**，
相对超出量 $d_{\max}/R = 1.015154$，且该比值与布站半径无关（尺度不变）。

## 关键观察

### 1. 直径与误差范围的关系
同为 3 个检测点：用例1（±1°，$D=3.4921$）与用例4（±1°，$D=12.0945$）直径差异巨大，
说明 **$D$ 主要由布站几何决定，而非仅由误差大小决定**。

### 2. 覆盖性不能只看直径或形状名称
- 用例1 六边形、用例4 六边形，前者能覆盖、后者不能；
- 判定依据是 $d_{\max}$ 与 $R=D/2$ 的**数值比较**，不存在"三角形就盖不住"这类简单规律。

### 3. 均匀布站的奇偶规律（来自 200 组随机与分析）
检测点均匀分布在圆周上、示向度指向圆心时：

| 布站 | $d_{\max}/R$ | 覆盖性 |
|---|---|---|
| 正三角形（3） | 1.015154 | 不能覆盖 |
| 正四、正六、正八边形（4/6/8） | 1.000000 | 恰好能覆盖 |
| 正五边形（5） | 1.010265 | 不能覆盖 |

即"**奇数布站盖不住、偶数布站刚好盖住**"，是回答"能否覆盖"时一个很有说服力的结论。
