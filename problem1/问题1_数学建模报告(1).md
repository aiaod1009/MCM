# 问题1 数学建模报告

## 无线电干扰源交会定位区域直径计算模型

---

## 1. 问题重述

已知若干个检测点坐标及某干扰源关于这些检测点的示向度，需要：
1. 给出采用交会定位法计算多边形定位区域直径的算法
2. 判断以定位区域直径为直径的圆能否覆盖此定位区域

**关键约束条件：**
- 示向度误差范围：$\pm 1°$
- 定位区域直径定义：区域内任意两点之间距离的最大值

---

## 2. 模型假设

1. **坐标系统假设：** 采用题目给定的平面直角坐标系，正东为 $x$ 轴正向，正北为 $y$ 轴正向
2. **误差对称假设：** 示向度误差在 $[-1°, 1°]$ 区间内均匀分布
3. **射线无限延伸假设：** 测向机检测的有效距离远大于目标区域尺度，可认为边界射线无限延伸
4. **检测点有效性假设：** 所有检测点都能有效接收到干扰源信号

---

## 4. 交会定位区域的几何模型

### 4.1 单个检测点的约束区域

对于检测点 $S_i = (x_i, y_i)$，测得示向度 $\theta_i$，考虑误差范围 $\pm 1°$，干扰源 $G$ 必定位于从 $S_i$ 出发的扇形区域内。

**扇形边界：**
- **左边界射线 $L_i^L$：** 从 $S_i$ 出发，方位角为 $\theta_i^L = \theta_i - 1°$
- **右边界射线 $L_i^R$：** 从 $S_i$ 出发，方位角为 $\theta_i^R = \theta_i + 1°$

**射线参数方程：**
$$L_i^L: \quad \vec{r}(t) = (x_i, y_i) + t \cdot (\cos\theta_i^L, \sin\theta_i^L), \quad t \geq 0$$
$$L_i^R: \quad \vec{r}(t) = (x_i, y_i) + t \cdot (\cos\theta_i^R, \sin\theta_i^R), \quad t \geq 0$$

### 4.2 多检测点交会定位区域

**定位区域 $\mathcal{R}$ 定义：**
$$\mathcal{R} = \bigcap_{i=1}^{n} \text{Sector}_i$$

其中 $\text{Sector}_i$ 是第 $i$ 个检测点对应的扇形区域。

**几何性质：**
- $\mathcal{R}$ 是多个凸扇形区域的交集，因此 **$\mathcal{R}$ 也是凸集**（凸集的交集仍为凸集）
- $\mathcal{R}$ 的边界由各检测点的边界射线构成

## 5. 定位区域直径计算算法

### 5.1 算法总体框架

**输入：**
- 检测点坐标列表 $\{S_i\}_{i=1}^n$
- 示向度列表 $\{\theta_i\}_{i=1}^n$

**输出：**
- 定位区域直径 $D$
- 直径对应的两个端点 $(V_p, V_q)$

**算法流程：**
1. 构造所有边界射线
2. 计算射线两两交点
3. 筛选有效顶点（在定位区域内的交点）
4. 计算凸包
5. 旋转卡壳算法求直径

### 5.2 射线交点计算

**问题：** 给定两条射线：
- 射线1：从 $S_i = (x_i, y_i)$ 出发，方向向量 $\vec{d}_1 = (\cos\alpha, \sin\alpha)$
- 射线2：从 $S_j = (x_j, y_j)$ 出发，方向向量 $\vec{d}_2 = (\cos\beta, \sin\beta)$

求交点 $P$。

**方程：**
$$S_i + t_1 \vec{d}_1 = S_j + t_2 \vec{d}_2$$

展开为：
$$\begin{cases}
x_i + t_1 \cos\alpha = x_j + t_2 \cos\beta \\
y_i + t_1 \sin\alpha = y_j + t_2 \sin\beta
\end{cases}$$

**解（用克莱姆法则）：**

令 $\Delta = \cos\alpha \sin\beta - \sin\alpha \cos\beta$（行列式）

如果 $\Delta \neq 0$（射线不平行），则：
$$t_1 = \frac{(x_j - x_i) \sin\beta - (y_j - y_i) \cos\beta}{\Delta}$$
$$t_2 = \frac{(x_j - x_i) \sin\alpha - (y_j - y_i) \cos\alpha}{\Delta}$$

**有效性判断：**
- 如果 $t_1 \geq 0$ 且 $t_2 \geq 0$，则交点 $P = S_i + t_1 \vec{d}_1$ 有效
- 否则两射线不相交（或在反向延长线上相交）

### 5.3 顶点筛选

对于计算出的候选交点 $P = (x_P, y_P)$，需要判断其是否在定位区域 $\mathcal{R}$ 内。

**判断准则：** $P \in \mathcal{R}$ 当且仅当对于所有检测点 $S_i$，$P$ 都在其扇形区域内。

**具体判断方法：**

计算从 $S_i$ 指向 $P$ 的向量的方位角：
$$\beta_i = \text{atan2}(y_P - y_i, x_P - x_i) \quad \text{（转换为 } [0°, 360°) \text{）}$$

判断 $\beta_i$ 是否在 $[\theta_i - 1°, \theta_i + 1°]$ 内（需处理角度跨越 $0°/360°$ 的情况）。

**注意跨越边界的处理：**

如果 $\theta_i - 1° < 0°$，则条件变为：
$$\beta_i \in [0°, \theta_i + 1°] \cup [\theta_i - 1° + 360°, 360°)$$

### 5.4 凸包计算

使用 **Graham扫描算法** 或 **Andrew算法** 计算有效顶点的凸包。

**输入：** 有效顶点集合 $\{P_k\}$

**输出：** 凸包顶点序列 $\{V_1, V_2, \ldots, V_m\}$（逆时针排列）

**算法简述（Graham扫描）：**
1. 选择最下方的点（$y$ 坐标最小，相同时取 $x$ 最小）作为基准点 $P_0$
2. 将其他点按相对 $P_0$ 的极角排序
3. 维护一个栈，遍历排序后的点，利用叉积判断转向
   - 如果构成右转（叉积 < 0），弹出栈顶
   - 否则将当前点入栈

**时间复杂度：** $O(m \log m)$，其中 $m$ 是候选点数量

### 5.5 旋转卡壳算法求直径

**原理：** 对于凸多边形，直径必定在顶点之间取得。旋转卡壳算法通过"旋转一对平行线卡住凸包"的方式，在 $O(m)$ 时间内找到最远点对。

**算法步骤：**

**输入：** 凸包顶点 $\{V_1, V_2, \ldots, V_m\}$（按逆时针排列）

**输出：** 直径 $D$ 和对应的顶点对 $(V_p, V_q)$

**伪代码：**
```
1. 初始化：i = 0, j = 1, D = 0
2. 循环 i 从 0 到 m-1：
   2.1 计算边 V[i] → V[(i+1) mod m] 的方向向量 edge_i
   2.2 当 cross(edge_i, V[(j+1) mod m] - V[j]) > 0：
       j = (j + 1) mod m  // 移动对向顶点
   2.3 dist = distance(V[i], V[j])
   2.4 如果 dist > D：
       D = dist
       (V_p, V_q) = (V[i], V[j])
3. 返回 D 和 (V_p, V_q)
```

**关键点解释：**
- `cross(edge_i, V[(j+1) mod m] - V[j])` 是向量叉积，用于判断是否应该移动 $j$ 指针
- 叉积 > 0 表示 $V[j+1]$ 相对于边 $V_i \to V_{i+1}$ 更远，应继续移动 $j$

**时间复杂度：** $O(m)$

## 6. 覆盖性分析

### 6.1 问题等价转化

**原问题：** 以定位区域直径 $D$ 为直径的圆能否覆盖此定位区域？

**等价问题：** 是否存在圆心 $C$，使得半径为 $R = D/2$ 的圆包含整个定位区域 $\mathcal{R}$？

### 6.2 理论分析（凸多边形情况）

**定理：** 对于凸多边形 $\mathcal{R}$，设其直径为 $D$（最远顶点对距离），则以直径为直径的圆**能够完全覆盖**该多边形。

**证明：**

设直径对应的顶点对为 $V_p = (x_p, y_p)$ 和 $V_q = (x_q, y_q)$，即：
$$D = \|V_p - V_q\| = \max_{i,j} \|V_i - V_j\|$$

取圆心为：
$$C = \frac{V_p + V_q}{2} = \left( \frac{x_p + x_q}{2}, \frac{y_p + y_q}{2} \right)$$

半径为：
$$R = \frac{D}{2}$$

**需要证明：** 对于任意顶点 $V_k$，有 $\|V_k - C\| \leq R$

**证明步骤（基于凸性和几何性质）：**

**引理：** 在凸多边形中，如果 $V_p$ 和 $V_q$ 是直径端点（通过旋转卡壳算法确定的最远点对），那么对于任意第三个顶点 $V_k$，从 $V_k$ 看 $V_p$ 和 $V_q$ 的张角满足：

$$\angle V_p - V_k - V_q \geq 90°$$

**证明引理（反证法）：**

假设存在顶点 $V_k$，使得 $\angle V_p - V_k - V_q < 90°$。

由余弦定理，在三角形 $V_p V_k V_q$ 中：
$$\|V_p - V_q\|^2 = \|V_p - V_k\|^2 + \|V_k - V_q\|^2 - 2\|V_p - V_k\| \cdot \|V_k - V_q\| \cdot \cos(\angle V_p - V_k - V_q)$$

当 $\angle V_p - V_k - V_q < 90°$ 时，$\cos(\angle V_p - V_k - V_q) > 0$，因此：
$$\|V_p - V_q\|^2 < \|V_p - V_k\|^2 + \|V_k - V_q\|^2$$

这意味着在三角形中，至少有一条边（$\|V_p - V_k\|$ 或 $\|V_k - V_q\|$）的长度大于 $\|V_p - V_q\|$，与 $V_p$ 和 $V_q$ 是最远点对矛盾。

因此，引理成立：$\angle V_p - V_k - V_q \geq 90°$

**基于引理完成主定理证明：**

由于 $\angle V_p - V_k - V_q \geq 90°$，根据**圆周角定理的逆定理**，顶点 $V_k$ 在以 $V_p V_q$ 为直径的圆上或圆内。

因此，对于圆心 $C = \frac{V_p + V_q}{2}$，半径 $R = \frac{D}{2}$，有：

$$\|V_k - C\| \leq R = \frac{D}{2}$$

即所有顶点都在圆内或圆上，圆能够完全覆盖整个凸多边形。

证毕。

### 6.3 结论

由于交会定位区域 $\mathcal{R}$ 是多个凸扇形的交集，因此 **$\mathcal{R}$ 是凸多边形**。

根据上述定理，**以定位区域直径为直径的圆能够覆盖此定位区域**。

**答案：能够覆盖。**

## 7. 算法复杂度分析

假设有 $n$ 个检测点：

| 步骤 | 操作 | 复杂度 |
|------|------|--------|
| 1 | 构造边界射线 | $O(n)$ |
| 2 | 计算射线交点（$2n$ 条射线，两两组合） | $O(n^2)$ |
| 3 | 筛选有效顶点（每个候选点检查 $n$ 个扇形约束） | $O(n^3)$ |
| 4 | 计算凸包（Graham扫描） | $O(m \log m)$，$m \leq O(n^2)$ |
| 5 | 旋转卡壳求直径 | $O(m)$ |

**总复杂度：** $O(n^3)$（顶点筛选步骤占主导）

对于实际问题（$n \leq 20$），该复杂度完全可接受。

## 9. 模型优点与局限

### 9.1 优点

1. **几何严谨性：** 完全基于解析几何，每一步都有明确的数学意义
2. **算法成熟：** 凸包和旋转卡壳是经典计算几何算法，有成熟实现
3. **可扩展性：** 可处理任意数量的检测点
4. **误差建模：** 显式考虑了示向度误差 $\pm 1°$

### 9.2 局限

1. **假设凸性：** 虽然理论上交会区域是凸的，但极端情况（如检测点过少或配置不佳）可能导致退化
2. **数值稳定性：** 射线接近平行时，行列式 $\Delta$ 接近 0，可能产生数值误差
3. **未考虑检测点在有效接收半径外的情况**

## 11. 建模总结

本模型建立了基于交会定位法的多边形定位区域直径计算方法，核心步骤包括：
1. 射线交点计算
2. 有效顶点筛选
3. 凸包构建
4. 旋转卡壳求直径

理论分析证明，对于凸多边形定位区域，**以直径为直径的圆能够完全覆盖该区域**。

该模型为后续问题2（第二检测点选择）和问题3（自动搜索定位）提供了理论基础。
