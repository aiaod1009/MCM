# 问题1：定位区域直径计算 - 完整实现

## 项目概述

本项目实现了交会定位区域直径的完整计算流程，包括：
1. 射线交点计算
2. 扇形区域判断
3. 凸包计算
4. 旋转卡壳算法求直径
5. 覆盖性验证
6. 结果可视化

## 核心模块说明

### 模块1: `ray_intersection.m` ✓

**功能**：计算两条射线的交点

**算法**：
- 使用参数方程：`P = O1 + t1 * D1` 和 `P = O2 + t2 * D2`
- 求解线性方程组
- 验证 `t1 >= 0` 且 `t2 >= 0`（交点在射线正向）

**测试状态**：通过 ✓
- 基本交点测试 ✓
- 平行射线检测 ✓

---

### 模块2: `point_in_sectors.m` ✓

**功能**：判断点是否在所有检测点的扇形区域内

**算法**：
- 计算从检测点到待测点的方位角
- 判断角度是否在 `[azimuth - error, azimuth + error]` 范围内
- 特殊处理跨越0度的扇形

**测试状态**：通过 ✓
- 基本扇形判断 ✓
- 跨0度扇形 ✓

---

### 模块3: `compute_convex_hull.m` ✓

**功能**：计算有效顶点的凸包

**算法**：
- 调用MATLAB内置 `convhull` 函数
- 去除返回结果中重复的首尾点

**测试状态**：通过 ✓

---

### 模块4: `rotating_calipers.m` ✓

**功能**：使用旋转卡壳算法计算凸包直径

**算法**：
- 对每条边，旋转对偶指针找最远点
- 使用叉积判断是否继续旋转
- 小凸包（≤3顶点）使用暴力枚举优化
- 时间复杂度：O(m)，m为凸包顶点数

**测试状态**：通过 ✓
- 正方形测试 ✓
- 三角形测试 ✓

## 主程序流程

`main_problem1.m` 执行以下步骤：

1. **加载数据**：读取检测点坐标、示向度、误差范围
2. **构造射线**：为每个检测点生成左右边界射线
3. **计算交点**：枚举所有射线对，计算有效交点
4. **筛选顶点**：保留在所有扇形内的交点
5. **计算凸包**：求有效顶点的凸包
6. **求直径**：使用旋转卡壳算法
7. **验证覆盖**：检查圆是否覆盖所有凸包顶点
8. **可视化**：生成图片和报告

### 测试用例1：简单三角形配置

**配置**：
- 检测点数量：3
- 检测点位置：(0, 0), (100, 0), (50, 80)
- 示向度：45°, 135°, 270°
- 误差范围：±1°

**结果**：
- 定位区域直径：**3.4921 米**（区域为六边形，6 个顶点）
- 有效顶点数量：6
- 覆盖性：**能够完全覆盖** ✓（$d_{\max}=R=1.7460$ m）

**说明**：三个扇形交出一个六边形区域，直径端点为 (50.00, 48.28) 与 (50.00, 51.78)。

### 测试用例2：五检测点配置

**配置**：
- 检测点数量：5
- 检测点位置：(0, 0), (200, 0), (200, 200), (0, 200), (100, 100)
- 示向度：45°, 135°, 225°, 315°, 0°
- 误差范围：±1°（**题面规定的误差**）

**结果**：
- 定位区域直径：**3.4311 米**（区域为细长四边形，4 个顶点）
- 有效顶点数量：4
- 覆盖性：**能够完全覆盖** ✓

**说明**：五个扇形在中心区域交出一个极细长的四边形（长 3.4311 m、宽约 0.1178 m，
长宽比 ≈ 29:1）。其中顶点 (100,100) 即第 5 个检测点自身（其示向度为 0°，该点是自己
楔形的顶点），是合法顶点，不可丢弃。

> **误差设定已纠偏（2026-09-12）**：早期版本把本用例误差人为放大到 ±5°，偏离了题面
> 规定的 $\pm1^\circ$。实测在 ±1° 下五个扇形同样有非空交集（$D=3.4311$ m），故已改回 ±1°。
>
> 细长形状是几何必然：只要某检测点本身是区域顶点，区域在该点必然以张角 $2\epsilon$ 的
> 楔形收敛，长宽比必然不小于 $1/(2\tan1^\circ)\approx28.6$。

**配置**：

**说明**：两个扇形的交集是四边形，**并非退化为单点**；旧版"$D=0$"是边界容差缺陷造成的假象。

### 测试用例4：等边三检测点（"圆盖不住"标准反例）

**配置**：
- 检测点数量：3，位于半径 300 m 的等边三角形顶点
- 示向度：均指向原点
- 误差范围：±1°

**结果**：
- 定位区域直径：**12.0945 米**（区域为六边形，6 个顶点）
- 有效顶点数量：6

该比值与布站半径无关（尺度不变），是回答"能否覆盖"的关键反例。

## 常见问题

### Q1: 未找到有效顶点？

**原因**：检测点的扇形区域没有公共交集。

**解决**：
1. 检查示向度配置是否合理
2. 增大误差范围
3. 调整检测点位置

### Q2: 覆盖圆不能完全覆盖？

**说明**：这是正常现象。判定依据只有一条：$d_{\max}\le D/2$ 是否成立。
形状名称给不出简单规律——同为六边形，用例1 能覆盖、用例4 不能覆盖。
均匀布站时有一个漂亮的规律：**奇数个检测点盖不住、偶数个刚好盖住**
（正三角 $d_{\max}/R=1.015154$、正五边形 $1.010265$、正四/六/八边形 $1.000000$）。

### Q3: 直径为0？

**原因**：正常情况下定位区域不会退化为点。若出现 $D=0$，先怀疑 **B1 边界容差缺陷**
（区域顶点恰好落在约束边界上时被浮点误差误杀）。用例3 旧版报"退化为单点、$D=0$"，
正是该缺陷造成的假象，修正后为四边形、$D=3.4921$ m。

**真正的退化**只有一种情形：某检测点自身落在其余所有扇形内且区域被压成一点，
此时该点（楔形顶点）应被保留，见缺陷 B5。

## 性能特点

- **时间复杂度**：
  - 候选交点：$\binom{2n}{2}$ 个（$n$ 为检测点数，共 $2n$ 条边界射线）
  - 扇形判断：O(m·n)，m 为候选点数 → 主导项，整体 **O(n³)**
  - 凸包计算：O(m log m)
  - 旋转卡壳：O(k)，k 为凸包顶点数

- **空间复杂度**：O(m)，主要存储候选交点
