## 核心模块说明

### 模块1: `ray_intersection.m` ✓

**功能**：计算两条射线的交点

**算法**：
- 使用参数方程：`P = O1 + t1 * D1` 和 `P = O2 + t2 * D2`
- 求解线性方程组
- 验证 `t1 >= 0` 且 `t2 >= 0`（交点在射线正向）

**测试状态**：通过 ✓
- 基本交点测试 ✓
- 平行射线检测 ✓

---

### 模块2: `point_in_sectors.m` ✓

**功能**：判断点是否在所有检测点的扇形区域内

**算法**：
- 计算从检测点到待测点的方位角
- 判断角度是否在 `[azimuth - error, azimuth + error]` 范围内
- 特殊处理跨越0度的扇形

**测试状态**：通过 ✓
- 基本扇形判断 ✓
- 跨0度扇形 ✓

---

### 模块3: `compute_convex_hull.m` ✓

**功能**：计算有效顶点的凸包

**算法**：
- 调用MATLAB内置 `convhull` 函数
- 去除返回结果中重复的首尾点

**测试状态**：通过 ✓

---

### 模块4: `rotating_calipers.m` ✓

**功能**：使用旋转卡壳算法计算凸包直径

**算法**：
- 对每条边，旋转对偶指针找最远点
- 使用叉积判断是否继续旋转
- 小凸包（≤3顶点）使用暴力枚举优化
- 时间复杂度：O(m)，m为凸包顶点数

**测试状态**：通过 ✓
- 正方形测试 ✓
- 三角形测试 ✓

---

### 模块5: `plot_localization_region.m` ✓

**功能**：可视化定位区域、边界射线、凸包和直径

**绘制内容**：

## 主程序流程

`main_problem1.m` 执行以下步骤：

1. **加载数据**：读取检测点坐标、示向度、误差范围
2. **构造射线**：为每个检测点生成左右边界射线
3. **计算交点**：枚举所有射线对，计算有效交点
4. **筛选顶点**：保留在所有扇形内的交点
5. **计算凸包**：求有效顶点的凸包
6. **求直径**：使用旋转卡壳算法
7. **验证覆盖**：检查圆是否覆盖所有凸包顶点
8. **可视化**：生成图片和报告

## 常见问题

### Q1: 未找到有效顶点？

**原因**：检测点的扇形区域没有公共交集。

**解决**：
1. 检查示向度配置是否合理
2. 增大误差范围
3. 调整检测点位置

### Q2: 覆盖圆不能完全覆盖？

**说明**：这是正常现象。对于某些凸包形状（如正三角形），以直径为直径的圆确实不能完全覆盖。只有当凸包退化为线段或点时，才能完全覆盖。

### Q3: 直径为0？

**原因**：定位区域退化为单点或非常小的区域。

**说明**：这表明扇形交集非常紧凑，是合理结果。

## 性能特点

- **时间复杂度**：
  - 射线交点：O(n²)，n为射线数量
  - 扇形判断：O(m·n)，m为候选点数
  - 凸包计算：O(m log m)
  - 旋转卡壳：O(k)，k为凸包顶点数
  - **总体**：O(n² + m·n)

- **空间复杂度**：O(m)，主要存储候选交点
